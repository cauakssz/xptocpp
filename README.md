# XPTO Bikes - Self-Service System

A console-based self-service system developed in **C++** to simulate the customer experience of a bicycle shop. The application allows users to browse products and maintenance services, manage a shopping cart, apply payment discounts, and complete purchases through an interactive menu-driven interface.

This project was developed to reinforce object-oriented and structured programming fundamentals by translating an existing algorithm from Portugol to C++, preserving its original business logic while adopting C++ syntax and standard libraries.

## Features

* Product catalog with promotional items
* Maintenance service listing
* Shopping cart management
* Automatic purchase total calculation
* 10% discount for cash payments
* Payment option validation
* Purchase summary generation
* Automatic cart reset after checkout

## Technologies
